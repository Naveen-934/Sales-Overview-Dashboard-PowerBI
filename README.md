# Sales Overview Dashboard - Power BI

## Project Objective

Developed an interactive Power BI dashboard to analyze sales performance, profit trends, quantity analysis, and regional sales insights using interactive visualizations and business intelligence techniques.

## Tools Used

* Power BI
* DAX
* Microsoft Excel

## Dashboard Features

* KPI Cards
* Sales Analysis
* Profit Analysis
* Region-wise Sales Insights
* Map Visualization
* Interactive Filters and Slicers
* Year-wise Comparison
* Quantity Analysis
* Year-wise Filtering
* Interactive Slicers

## Business Insights

* Identified high-performing sales periods
* Compared yearly profit trends
* Analyzed quantity distribution across categories
* Improved business reporting visualization
